# IRS 2025 Review Packets

Review packets for federal tax year 2025 artifacts will live here.

Expected packet types:

- source review
- topic review
- rule review
- question/content review
- evidence mapping review
- conflict rule review
- scenario expected-outcome review
- release readiness review

No artifact in this prototype should be considered runtime-approved until a review packet records the human approvals required by `workflows/irs-2025-artifact-production.yaml`.
